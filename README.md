# TEKMentors homepage redesign

Design and prototype workspace for the new tekmentors.com homepage,
prepared by TechnoTaau Team for TEKMentors Consulting, Gurugram.

Start with `CLAUDE.md`, then the numbered docs in `docs/`.

```
CLAUDE.md                  working rules for anyone (human or agent) in this repo
docs/                      brief, brand, content, homepage spec, workflow, research log
design/tokens.css          design tokens (color, type, spacing, radius, shadow)
design/reference/          the Claude Design canvas export, chats, uploads, previews
assets/brand/              logo files pulled from the live site
.claude/agents/            subagent definitions for the design team
prototype/                 (Phase 4) static HTML/CSS homepage prototype
```

Status: Phase 0 (context and workflow) and Phase 1 (canvas reconciliation)
complete. Waiting on Gate 1 decisions in `docs/06-reconciliation-memo.md`.
See `docs/04-workflow.md`.
